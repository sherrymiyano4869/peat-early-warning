# Dua bahasa (ID/EN): cara kerja dan sisa pekerjaan

Pilihan bahasa ada di bilah atas semua halaman (tombol ID | EN). Bahasa Indonesia tetap sumber di HTML dan JavaScript; bahasa Inggris dipasang dengan
mencocokkan teks ke kamus `webmap/i18n-en.js`. Pilihan tersimpan di `localStorage` ("lang"); `?lang=en` atau `?lang=id` memaksa bahasa.

## Cara kerja (`webmap/i18n.js`)

* Menelusuri simpul teks dan atribut `aria-label`, `title`, `alt`, `placeholder`. Yang kuncinya ada di kamus diganti; yang tidak ada dibiarkan (nama orang, merek, istilah umum).
* Konten yang dibuat JavaScript sesudah halaman dimuat ikut diterjemahkan (MutationObserver) selama teksnya **persis sama** dengan kunci kamus.
* Kunci kamus = teks Indonesia persis, spasi ganda dan baris baru dinormalkan menjadi satu spasi. Entitas HTML (`&middot;`) dibaca sebagai karakternya (`·`).
* API: `window.I18N.t("teks")`, `window.I18N.f("Stasiun di bawah {n} cm", { n: 40 })` untuk kalimat bervariabel, `window.I18N.add({...})`, `window.I18N.set("en")`, peristiwa `langchange`.
* Halaman `monitoring`, `prediction`, `response`, `petugas` menampilkan catatan kecil di bahasa Inggris ("panel data, legenda, dan label peta masih Indonesia") sampai terjemahannya lengkap; hapus namanya dari `PARTIAL` di `i18n.js` bila sudah selesai.

## Pekerjaan berikutnya (untuk penulis webmap)

1. Isi kolom `inggris` di `docs/i18n_belum_diterjemahkan.tsv`, lalu pindahkan pasangannya ke `webmap/i18n-en.js` (skrip pembantu boleh ditulis).
2. Kalimat yang disusun di JavaScript dari potongan dan angka (mis. `app.js`, `response.js`, `petugas.js`) tidak akan cocok dengan kamus. Ubah menjadi `I18N.f("Stasiun di bawah {n} cm", { n })` dengan kunci berisi `{n}`, dan jangan menyambung kalimat dari potongan.
3. Format angka dan tanggal mengikuti bahasa: sekarang `toLocaleString("id-ID")` tetap; bahasa Inggris memakai `en-GB` bila `I18N.lang === "en"` (dengarkan `langchange` untuk menggambar ulang).
4. Rangkaian terjemahan teknis (skill, kepercayaan, PR-AUC, persistensi, klimatologi) harus konsisten antarhalaman; satu istilah, satu padanan.
5. Mintalah penutur bahasa Inggris memeriksa halaman Tentang, Tim, dan Lapor sebelum diterbitkan sebagai versi final.
