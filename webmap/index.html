Peringatan dini kekeringan dan kebakaran gambut

Prototipe riset untuk gambut Jambi: kondisi kini, peluang titik api di sel 1 km, dan verifikasi lapangan. Estimasi riset, bukan peringatan resmi.

Monitoring: kondisi kini

Kerentanan struktural gambut, titik api yang teramati, dan muka air di stasiun SiTMAT.

Estimasi saja, tanpa prakiraan.

Prediksi: 1–14 hari

Peluang ada titik api di sel 1 km (1–3 hari) dan prakiraan muka air stasiun (7–14 hari), dengan status bukti dan kepercayaan.

Peluang per sel, bukan titik pasti.

Respons: laporan lapangan

Laporan warga dan petugas dicocokkan dengan satelit, tugas pemeriksaan, dan penilaian prediksi terhadap kejadian sesudahnya.

Per sel 1 km; titik laporan tidak ditampilkan.

Petugas: tugas pemeriksaan

Daftar tugas terbitan terakhir dan pencatatan status kunjungan. Hasil kejadian tetap dilaporkan lewat formulir Kobo.

Tampilan ponsel.

Buka lewat server: python -m http.server -d webmap 8000, atau uvicorn api.app:create_app --factory bila ingin mencatat status tugas.
