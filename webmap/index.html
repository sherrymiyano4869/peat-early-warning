PERINGATAN DINI UNTUK GAMBUT TROPIS

Peringatan dini kekeringan dan kebakaran gambut

Peluang titik api dan pengeringan muka air untuk setiap sel 1 km gambut Jambi, diterjemahkan menjadi tugas pemeriksaan bagi petugas lapangan. Prototipe riset, bukan peringatan resmi.

Cara kerja

Dari piksel satelit sampai ke pintu yang tepat

  1. 1

    Kumpulkan

    Titik api VIIRS, hujan, kelembapan tanah, NDMI, dan muka air stasiun SiTMAT.

  2. 2

    Prediksi

    Model memberi skor peluang titik api dan penurunan muka air untuk setiap sel 1 km.

  3. 3

    Periksa

    Sel berpeluang tertinggi, ditambah sampel acak, menjadi tugas pemeriksaan lapangan.

  4. 4

    Nilai

    Prediksi yang sudah diarsipkan dinilai terhadap laporan lapangan dan satelit sesudahnya.

DALAM PRAKTIK

Peta peluang untuk setiap sel 1 km

Model memberi skor setiap sel gambut, memeringkat sel yang sebaiknya diperiksa lebih dulu, dan menampilkan tingkat kepercayaannya.

  • Peluang titik api besok dan 3 hari ke depan
  • Prakiraan penurunan muka air 7 dan 14 hari
  • Status bukti dan kepercayaan ditampilkan untuk setiap model
  • Diuji retrospektif; penilaian prospektif memakai arsip prediksi
